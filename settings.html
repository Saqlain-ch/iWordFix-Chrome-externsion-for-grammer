How to Get Your API Keys

OpenAI API Key

  1. Go to OpenAI Platform
  2. Sign in to your account or create one
  3. Click "Create new secret key"
  4. Copy the generated key (starts with "sk-")
  5. Paste it in the OpenAI field above and click "Save"

DeepSeek API Key

  1. Go to DeepSeek Platform
  2. Sign in to your account or create one
  3. Click "Create new secret key"
  4. Copy the generated key (starts with "sk-")
  5. Paste it in the DeepSeek field above and click "Save"

About This Extension

What It Does

This extension helps you write professional email responses and correct grammar using AI. It integrates seamlessly with Gmail to provide context-aware assistance.

Key Features

  • Email Response Writer: Generate professional email replies with Gmail context integration
  • Grammar Helper: Fix grammar, spelling, and improve writing clarity
  • Gmail Integration: Automatically insert responses into Gmail reply boxes
  • Smart Context: Understands email threads and responds appropriately
  • One-Click Copy: Easy copying and pasting of AI responses

How to Use

  1. For Email Responses: Check "Include email context" and write your prompt. The AI will analyze the email thread and write a response on your behalf.
  2. For Grammar Help: Leave the checkbox unchecked and paste your text. The AI will fix grammar, spelling, and improve clarity.
  3. Use in Gmail: Click "Use in Reply" to automatically insert the response into Gmail's reply box.

Privacy & Security

  • Your API key is stored locally in Chrome's storage
  • It's never sent to our servers or shared with third parties
  • You can clear it at any time using the "Clear" button
  • Keep your API key secure and don't share it publicly
